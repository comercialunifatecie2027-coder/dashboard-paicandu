# Dashboard Comercial Paiçandu

Dashboard de leads, matrículas e conversão do polo Paiçandu (dados do Datacrazy, atualizado a cada 30 s).

O acesso é por senha. A chave do Datacrazy só aparece aqui **criptografada** com essa senha (PBKDF2-SHA256, 600.000 rodadas) e é aberta no navegador de quem digita a senha certa.
